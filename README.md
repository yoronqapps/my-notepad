#  My Notepad

A lightweight desktop notepad built with React + Electron.

Wanted something simple with image pasting capabilities but didn't want 
to use Notion — it's kinda heavy for just taking quick notes.

## Features
-  Paste or drag photos directly into your notes
-  Timestamps on paragraphs so you know when you wrote what
-  Save notes as `.html` (with images) or `.txt`
-  Runs as a real desktop app, works fully offline

## Built with
- [React](https://react.dev)
- [Electron](https://www.electronjs.org)

## Run locally
npm install
npm run electron-dev

## Build installer
npm run electron-build
